# Dashboard Toko

Dashboard admin/POS offline-first untuk warung minuman & snack kedelai (Mas Andik).
Semua data tersimpan lokal di HP (IndexedDB via Dexie), UI bahasa Indonesia, login
Owner/Admin dengan hak akses berbeda.

Fitur utama: Beranda pemilihan produk + keranjang, Pelanggan/member, Stok,
Dompet (keuangan harian, owner-only), Histori (`/laporan`), dan Setting.

Lihat `AGENTS.md` untuk arsitektur & aturan bisnis, `DEPLOY.md` untuk cara
menjalankan/deploy.
